Student Performance Analyzer

A simple Python-based student performance management and analysis system.

About the Project

The Student Performance Analyzer allows users to enter student marks for three subjects (M1, M2, and M3) and automatically analyze their academic performance.

The program calculates total marks, average marks, grade, and PASS/FAIL result. It also provides options to display all students, find the topper, search for a student, and view class statistics.

Features

• Add student records
• Enter M1, M2, and M3 marks
• Calculate total marks
• Calculate average marks
• Assign grades automatically
• Determine PASS or FAIL
• Display all student records
• Find the topper
• Search for a student by name
• Calculate class statistics
• Calculate pass percentage
• Menu-driven interface

Grade System

Average Marks Grade

90 or above  A+   
80–89.99     A    
70–79.99     B    
60–69.99     C    
50–59.99     D    
Below 50     F    

Pass/Fail Rule

A student is marked PASS only if all three subject marks are at least 40.

If any subject mark is below 40, the student is marked FAIL.
